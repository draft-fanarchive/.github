# DRAFT
_Draft_ is a fanfic archive on the AT Protocol, much like the [Archive of our Own](archiveofourown.org/), but using a different technology stack. _Please do not take this too seriously;_ I have no intention that this project becomes some sort of competitor to the Archive, nor any expectation that the Archive will borrow a single line of code I write here. I'm doing this to teach myself some new(-ish) technologies-- in particular get a sense of the AT Protocol and its proposed permission data model, as well as finally give SvelteKit's remote functions a try.

But even if the point of this project is purely educational, I still want to give Draft the best possible user experience, and try out a few ideas I think would make for a better reading and authoring experience. I think this has a really exciting take on work tags, and a look and feel that makes commenting on what you read easier.

If you see a bug or have a suggestion, please feel free to open an issue in the appropriate repository. Currently, this project is spread across
- **draft-fanarchive/.github**, this repository, used to maintain the github page, and to track issues that affect multiple other repositories. If you have a high-level feature request, this is the place to open it. 
- **[draft-fanarchive/schemata](https://github.com/draft-fanarchive/schemata)**, Defines AT Proto schemata for fanworks and feedback, as well as the types and queries in the archive's API.
